นโยบายความเป็นส่วนตัว — Pete-Hermes

Pete-Hermes เป็นเครื่องมือของผู้ดูแลเพจสำหรับเตรียมเนื้อหา เผยแพร่โพสต์และวิดีโอ และตรวจสถานะการเผยแพร่บนเพจ Facebook ที่ผู้ดูแลอนุญาตให้เข้าถึง ไม่ใช่บริการที่เปิดให้บุคคลทั่วไปสมัครใช้งานในขณะนี้

ข้อมูลที่ใช้

  • รหัสและชื่อบัญชีที่อนุญาตแอป รหัสและชื่อเพจ รายการเพจและงานที่บัญชีมีสิทธิ์จัดการ
  • สิทธิ์การอนุญาตและ Access Token เพื่อเรียก Meta API ตามสิทธิ์ที่อนุญาต
  • ไฟล์วิดีโอ รูปภาพ และข้อความที่ผู้ดูแลเลือกเผยแพร่ รวมถึงรหัสโพสต์/Reel ลิงก์ สถานะและเวลาที่เกี่ยวข้อง
  • บันทึกการทำงานและการตรวจสอบ เช่น รหัสไฟล์ ขนาดไฟล์และค่าแฮช เพื่อยืนยันการส่งมอบและป้องกันการโพสต์ซ้ำ

วัตถุประสงค์

ใช้เพื่อระบุเพจที่ได้รับอนุญาต เผยแพร่เนื้อหาตามคำสั่งผู้ดูแล ตรวจผล แก้ข้อผิดพลาดและป้องกันการเผยแพร่ซ้ำ แอปไม่ได้มีวัตถุประสงค์จำหน่ายข้อมูลส่วนบุคคลหรือใช้เพื่อโฆษณาเจาะกลุ่ม

การจัดเก็บและผู้ให้บริการที่เกี่ยวข้อง

ข้อมูลการทำงานและข้อมูลรับรองถูกจัดเก็บในสภาพแวดล้อมของผู้ดูแล บางไฟล์เนื้อหาและเอกสารแคปชันจัดเก็บใน Google Drive/Docs ตามขั้นตอนทำงาน เนื้อหาที่สั่งเผยแพร่และข้อมูลที่จำเป็นถูกส่งไป Meta ผู้ให้บริการเหล่านี้ประมวลผลข้อมูลตามนโยบายของตน

เว็บไซต์เอกสารนี้เป็นหน้าแบบคงที่บน GitHub Pages ไม่มีแบบฟอร์มสมัครใช้งานหรือสคริปต์ติดตามที่แอปเพิ่มเอง การเข้าเว็บไซต์อาจมีข้อมูลทางเทคนิคที่ผู้ให้บริการโฮสติ้งประมวลผลตามนโยบายของตน

ระยะเวลาและการลบข้อมูล

ข้อมูลรับรองเก็บระหว่างที่ใช้การเชื่อมต่อ บันทึกเนื้อหาและผลเผยแพร่เก็บเพื่อประวัติและป้องกันการโพสต์ซ้ำ ขณะนี้ไม่มีรอบลบอัตโนมัติ ผู้ดูแลสามารถรับคำขอให้ตรวจสอบและลบข้อมูลที่เกี่ยวข้องได้ตามหน้าคำแนะนำการลบข้อมูล การถอนสิทธิ์ไม่ลบเนื้อหาที่เผยแพร่บน Facebook หรือสำเนาในบริการอื่นโดยอัตโนมัติ

ความปลอดภัยและการควบคุมสิทธิ์

ข้อมูลรับรองไม่ควรอยู่ใน repository สาธารณะและไม่ใช่ส่วนหนึ่งของเว็บไซต์เอกสารนี้ ผู้อนุญาตสามารถถอนการเชื่อมต่อผ่านการตั้งค่า Facebook/Meta ที่เกี่ยวข้อง หรือขอให้ผู้ดูแลยุติการเชื่อมต่อ
